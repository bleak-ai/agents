# Commands

User-invokable entry points, exposed as slash commands in the client.

## Contents

- `setup.md`: set up browser-cookbook (choose Chrome instance, verify debug connection, explain layout).
- `run_once.md`: do a browser task without saving a recipe.
- `run_create_cookbook.md`: do a browser task and crystallize it into a recipe.
- `run_recipe.md`: run a saved recipe by name, with self-healing on failure.
- `recipe.md`: generated-command template, registers one prompt per saved recipe.

# Voice

Every headline, hook, body block, and close must pass this file. The headline
workshop scores voice fit against it. Product-specific overrides live in the
"Voice notes" section of `products/<slug>/info.md`.

## Rules

- Plain developer prose. Write like one person explaining a tool to another.
- First person or direct address. Never corporate "we are excited to".
- No exclamation points.
- No marketing buzzwords (see banned words).
- No filler phrases: "in today's world", "it's no secret that", "at the end
  of the day", "game changer", "take it to the next level".
- Claims must be concrete. If a sentence works for any product, rewrite it.
- Short sentences beat subordinate clauses.

## Banned words

streamline, revolutionize, seamless, supercharge, unlock, empower, elevate,
effortless, cutting-edge, next-level, game-changing, blazingly

Edit this list freely. The agent must never remove entries on its own.

## Lines that sound right

Sentences the user wrote or rewrote during runs. When the user replaces a
proposed text with their own wording, append the user's version here with the
date and product. The agent appends; the user prunes.

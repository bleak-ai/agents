# Intake: shipnotes-launch

- **Product**: shipnotes, a CLI that turns merged pull requests into a readable changelog.
- **Goal**: launch (first public release).
- **Segment**: solo maintainers of small open-source tools. Awareness stage: problem aware (they know changelogs rot, they do not know tools fix it).
- **Key differentiator**: reads the diff, not the commit messages, so lazy commit logs still produce a correct changelog.
- **Past posts**: none for this product.

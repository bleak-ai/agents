# Steps

The craft command follows these steps in order.

1. [0-intake](0-intake.md) - Load product knowledge from `products/` (state root). Pick the segment. Confirm the goal.
2. [1-angle](1-angle.md) - Choose the single claim or story of this post. User picks from 3-5 proposals.
3. [2-headline](2-headline.md) - Generate 15-25 candidates, score them, red-team the top 5. User picks and refines.
4. [3-body](3-body.md) - Draft the body: System 1 hook, System 2 proof, close with click-path check.
5. [4-assemble](4-assemble.md) - Combine headline + body. Save the final post.

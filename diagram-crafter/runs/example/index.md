# Run: example task-queue diagram

Fabricated example run for a fictional product, showing the artifact shape
of the first two steps. Claim: workers pull jobs, they never receive them.
Audience: backend developers evaluating the queue.

- `0-intake/`: intake results; source, audience, claim, prior art.
- `1-wireframe/`: the candidate wireframes and the approved one.
- `done/`: marker with the finish date and the saved path.

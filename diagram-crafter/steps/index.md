# Steps

The craft command follows these steps in order. Each step reads the
previous step's output from the run folder and writes its own.

- `0-intake.md`: take the text and audience; one round of scoping questions pins down the claim.
- `1-wireframe.md`: 2-3 ASCII composition options with real labels; the user picks one or asks for a mix.
- `2-draft.md`: expand the chosen wireframe into an SVG using the archetype skeleton and the design system.
- `3-review.md`: best-effort render and self-check, then the feedback loop with the user.
- `4-save.md`: save the final SVG to diagrams/ with its metadata header.
